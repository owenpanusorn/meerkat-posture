# ข้อความแนะนำ Meerkat (สำหรับแชตไลน์)

ส่งรูป [images/buddy.png](images/buddy.png) ก่อน แล้วคัดลอกข้อความด้านล่างไปวางต่อ

~~~text
😩 ใครเป็นบ้าง?
• ปวดคอ บ่าตึง หลังนั่งทำงานทั้งวัน
• ปวดหลัง ปวดเอว ลุกจากเก้าอี้ทีต้องบิดตัว
• ตาล้า ตาแห้ง เพราะจ้องจอไม่ได้พัก
• นั่งเพลินจนลืมเวลา ทั้งที่ควรลุกขยับทุก 35–60 นาที แต่รู้ตัวอีกทีก็ผ่านไป 3–4 ชั่วโมงแล้ว
• รู้ตัวอีกทีก็หลังค่อม คอยื่นเข้าหาจอไปแล้ว

ส่วนใหญ่ไม่ได้มาจากงานหนัก แต่มาจากการนั่งท่าผิดและนั่งนานเกินไปโดยไม่รู้ตัว 🫠

🦦 เลยทำแอป Meerkat ขึ้นมา เป็นมีแอร์แคทตัวเล็ก ๆ นั่งอยู่มุมจอ คอยดูท่านั่งผ่านเว็บแคม
• ก้มคอหรือหลังงอนานเกินไป → เตือนให้นั่งตรง
• ⏰ นั่งนานเกินไป → เตือนให้ลุกยืดเส้น (ได้พักสายตาไปด้วย) ถ้ายังไม่ลุก จะเตือนซ้ำจนกว่าจะลุก ยังนั่งดื้ออยู่อีก มีแอร์แคทจะเริ่มกระโดดเรียกเลย 🐾

🔒 เรื่องความเป็นส่วนตัว
• ไม่บันทึกภาพหรือวิดีโอเลย
• ทำงานออฟไลน์ ไม่ส่งข้อมูลออกไปไหน
• กดหยุดแล้วกล้องปิดจริง ไฟกล้องดับ
~~~
